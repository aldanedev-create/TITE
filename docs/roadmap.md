# Tite Roadmap

## Overview

This document outlines the planned development roadmap for Tite. Features are organized by version and priority.

## Version 1.0.0 (Current)

### Core Features

- [x] Project creation (`tite new`)
- [x] Development server with hot reload (`tite dev`)
- [x] Health checks (`tite doctor`)
- [x] Clean artifacts (`tite clean`)
- [x] Project info (`tite info`)
- [x] Configuration management (`tite config`)
- [x] Environment info (`tite env`)
- [x] Version display (`tite version`)

### Modes

- [x] Default mode
- [x] Data Science mode
- [x] AI/ML mode
- [x] Automation mode
- [x] Web mode
- [x] API mode
- [x] Library mode
- [x] CLI mode
